# Sitio web de J.C. MarqzRa

Sitio estático para GitHub Pages.

## Publicación

1. Crea un repositorio público en GitHub, por ejemplo `jc-marqzra-web`.
2. Desde esta carpeta ejecuta:
   ```bash
   git init
   git add .
   git commit -m "Primera versión de la web"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/jc-marqzra-web.git
   git push -u origin main
   ```
3. En GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.
4. Visita `https://TU-USUARIO.github.io/jc-marqzra-web/` cuando termine el despliegue.

## Personalización

- Reemplaza la ilustración CSS de la puerta por tu portada cuando quieras.
- Coloca el PDF gratuito en `assets/primer-cuento.pdf` y habilita el enlace comentado en `index.html`.
- Sustituye las tiendas sin enlace por enlaces reales cuando se apruebe el libro.
